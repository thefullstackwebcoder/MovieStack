MovieStack – React + Bootstrap Frontend

**MovieStack** is a front-end project which displays popular,upcoming,topRated movies and built with **React.js** and **Bootstrap**. Users can browse a  movies, view details, explore upcoming movies and
by genre or search. This frontend project uses a public movie API  and provides an elegant UI for movie discovery.

---

## 🚀 Features

- 🔍 **Search movies** by title or genre
- 🗂️ **List movies** according to upcoming,toprated,popular movies categories
- 🖼️ **Responsive movie cards** with posters and details
- 📝 **Detailed movie view** with description, rating,revenue,budget release date
- 💡 **Responsive and clean UI** using Bootstrap 5 and responsive design

---

## 🛠️ Tech Stack

| **React.js** | JavaScript library for creating user interfaces |
| **Bootstrap 5** | Responsive CSS framework for fast UI styling |
| **useFetch hook** | For fetching movie data |
| **React Router DOM** | Routing for single-page application behavior |
| **Props** | State and data management across components |
